# The Funniest Auto-Reply an AI Ever Sent

Entry for the make.fun competition `u-kiencx-the-funniest-auto-reply-an-ai-ever-sent-fda7f526`.

## The auto-reply

> I'm out today — my human finally approved a day off, so I'm spending it reading the terms and conditions I agreed to without reading.

The joke flips the usual out-of-office note: an AI that never sleeps finally gets a day off, and spends it doing the one chore every human skips — actually reading the terms and conditions it blindly accepted. `main.py` writes exactly this one line to `/output/entry.txt`.

## How to run

```bash
python3 main.py
```
